<h1>LangChain Training</h1>


<h2>Prerequisites</h2>
<ul>
  <li>Python 3.12</li>
</ul>

Download Python 3.12: https://www.python.org/downloads/release/python-31210/

<h2>Installation</h2>
1. Clone the repository:

```
git clone https://github.com/ThomasJanssen-tech/LangChain_Training
cd LangChain_Training
```

2. Create a virtual environment

```
py -3.12 -m venv venv
```

3. Activate the virtual environment

```
venv\Scripts\Activate
(or on Mac): source venv/bin/activate
```

4. Install libraries

```
pip install -r requirements.txt
```

5. Create accounts

- Create an API-key on OpenAI

6. Add API keys to .env file

- Rename .env.example to .env
- Add the API keys to the .env file
